EasyMySQL

Deine eigene Datenbank, schnell eingerichtet

Ein MariaDB-Server und alles, um damit zu arbeiten, in einem Fenster: Abfragen, Tabellen, Diagramme, Sicherungen.

Für Windows herunterladen

Portable (ZIP)

Kostenlos und quelloffen, Windows 64-bit. Warnt Windows vor einem unbekannten Herausgeber: „Weitere Informationen“ und „Trotzdem ausführen“.

  • Server inklusive

    MariaDB gehört zum Programm und startet mit ihm. Es nimmt nur Verbindungen vom eigenen PC an.

  • Ein Server pro Datei

    Jede Abfragedatei kann einen eigenen Server nutzen, auch über SSH-Tunnel. Standard ist der globale.

  • Abfragen und Tabellen

    Ein Editor mit Vorschlägen und Fehlermarkierung, Tabellen zum direkten Bearbeiten und ein Abfrage-Assistent mit dem SQL daneben.

  • Klare Diagramme

    Auch große Datenbanken werden kreuzungsarm mit rechtwinkligen Linien angeordnet.

  • Import und Export

    MariaDB, MySQL, PostgreSQL, SQLite, MongoDB, Redis und CSV. Als Dateien oder direkt von und zu anderen Servern.

  • Sicher und aktuell

    Sicherungen vor riskanten Befehlen und nach Zeitplan. Updates installieren sich im Hintergrund.
