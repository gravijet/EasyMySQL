EasyMySQL

Ein MariaDB-Server, ein SQL-Editor und die Brücke zu deiner KI – in einer App. Ein Befehl, und die Datenbank läuft.

Für Windows, macOS und Linux. Kostenlos und quelloffen.

MariaDB [easymysql]> SELECT feature, what FROM app;

Alles, was eine Datenbank braucht, in einem Fenster.

6 rows in set (0.00 sec)

Deine KI liest deine Datenbank.

EasyMySQL enthält einen MCP-Server. Claude Code, Codex, Cursor und andere Assistenten sehen deine Tabellen, schreiben passendes SQL und beantworten Fragen mit deinen echten Daten.

Liest zuerst
Schema, Schlüssel und Beziehungen, bevor eine Abfrage entsteht.
Nur lesend
Jede Abfrage läuft in einer READ-ONLY-Transaktion, bis du Änderungen erlaubst.
Sichert vorher
Vor DROP, TRUNCATE oder DELETE ohne WHERE sichert EasyMySQL die Datenbank.

Claude Code und Codex verbinden

easymysql setup-ai

Oder als Plugin in Claude Code

/plugin marketplace add gravijet/EasyMySQL

In Codex

codex plugin marketplace add gravijet/EasyMySQL

Ein Befehl.

Das Skript lädt die neueste Version, prüft ihre SHA-256-Prüfsumme, installiert EasyMySQL und bietet an, deine KI-Assistenten zu verbinden. Sonst nichts.

Windows

Windows 10 und 11, 64-bit. MariaDB ist dabei.

PowerShell

irm https://mysql.benjaminberger.at/install | iex

Eingabeaufforderung (cmd)

powershell -c "irm https://mysql.benjaminberger.at/install | iex"
