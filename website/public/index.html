Was man hat, sobald der Server läuft

SQL-Editor

Dateien mit beliebig vielen Anweisungen. Ausführen lässt sich die ganze Datei, die Markierung oder nur die Anweisung am Cursor. Jedes Ergebnis bekommt einen eigenen Reiter, Fehler werden an der Stelle unterstrichen.

  • Vorschläge für Tabellen, Spalten und Funktionen beim Tippen, nach „alias.“ erscheinen die Spalten
  • EXPLAIN für die aktuelle Anweisung: welche Indizes benutzt werden
  • Formatierer, der Kommentare, Texte und Prozeduren in Ruhe lässt und beim zweiten Mal nichts mehr ändert
  • Suchen, Ersetzen, Gehe zu Zeile, Minimap, Klammerhervorhebung
  • Ergebnisse als CSV, JSON, SQL, INSERT-Anweisungen, Markdown oder direkt für Excel kopiert

Tabellen und Daten

Tabelle per Doppelklick öffnen, mit einer WHERE-Bedingung filtern, Zellen direkt bearbeiten. Enter speichert sofort, Esc bricht ab.

  • Spalten hinzufügen, ändern und löschen; Indizes (normal oder eindeutig, auch über mehrere Spalten)
  • Fremdschlüssel mit Verhalten beim Löschen und Ändern, auch die eingehenden anderer Tabellen
  • Tabellen-Designer für neue Tabellen, „SQL anzeigen“ zeigt die CREATE-Anweisung
  • Ganze Datenbank als .sql exportieren, Tabellen in der Reihenfolge ihrer Abhängigkeiten; .sql-Dateien importieren und ausführen

ER-Diagramm

Liest Tabellen, Schlüssel und Fremdschlüssel einer Datenbank aus und zeichnet die Beziehungen. Von Hand anordnen oder automatisch: verbundene Tabellen nebeneinander, möglichst wenige Kreuzungen.

  • 1:n, 1:1 und n:m, optionale Beziehungen markiert; Krähenfuß, Chen oder (min,max)
  • Beziehung von Spalte zu Spalte ziehen: Fremdschlüssel oder Zwischentabelle werden angelegt
  • Die Anordnung wird je Datenbank gespeichert
  • Export als SVG oder als CREATE-TABLE-Skript für alle Tabellen

Abfrage-Assistent

Baut SELECT-Abfragen aus Bausteinen, von „alle Spalten einer Tabelle“ bis zu verschachtelten Unterabfragen mit WITH, UNION und Fensterfunktionen. Das erzeugte SQL steht immer daneben, formatiert.

  • JOINs bieten zuerst die über Fremdschlüssel verbundenen Tabellen an und füllen die ON-Bedingung aus
  • Im Editor öffnen, kopieren oder als Sicht speichern
  • Der Inhalt wird laufend gespeichert und ist nach einem Neustart wieder da

Ein Projekt ist einfach ein Ordner mit SQL-Dateien, auf der Festplatte, einem USB-Stick oder in einem Cloud-Ordner. Offene Registerkarten, unbenannte Abfragen und der Abfrage-Assistent sind nach einem Neustart wieder da.

Sicherheit

Eine Sicherung, bevor etwas schiefgeht

EasyMySQL geht davon aus, dass früher oder später ein DROP zu viel passiert und der Strom im ungünstigsten Moment ausfällt.

Vor gefährlichen Anweisungen

Bei DROP, TRUNCATE sowie DELETE oder UPDATE ohne WHERE wird die betroffene Datenbank vorher gesichert. Schlägt die Sicherung fehl, wird nichts ausgeführt.

Nach Zeitplan

Beim Start und standardmäßig alle 2 Stunden. Aufbewahrt werden die neuesten 10 und eine je Tag für 14 Tage. Der Ordner ist frei wählbar, etwa ein USB-Stick oder Netzlaufwerk.

Absturzsicher

InnoDB schreibt jede bestätigte Änderung sofort auf die Festplatte. Nach einem Stromausfall stellt MariaDB beim nächsten Start alles wieder her, danach werden alle Tabellen geprüft.

Reparatur

Alle Tabellen prüfen oder reparieren, MyISAM nach InnoDB umwandeln und „Server retten“, falls MariaDB nicht mehr startet: der alte Datenordner bleibt unverändert beiseite liegen.

Fragen

Fragen, die aufkommen

Muss ich MariaDB extra installieren?

Nein. Setup und portable ZIP enthalten einen vollständigen MariaDB-Server samt Kommandozeilenwerkzeugen wie mysql und mysqldump.

Wie verbinde ich mich?

Server 127.0.0.1, Port 3306, Benutzer root, kein Passwort. In der Eingabeaufforderung: mysql -u root, solange der Server läuft.

Ist der Server von anderen Rechnern erreichbar?

Nein. Er nimmt standardmäßig nur Verbindungen vom eigenen PC an.

Was passiert, wenn ich das Fenster schließe?

Das Fenster verschwindet, der Server läuft weiter und das Symbol bleibt im Infobereich neben der Uhr. Richtig beenden über Datei → Beenden oder das Menü des Symbols. Mit Windows startet der Server nicht von selbst.

Können Excel oder Access die Datenbanken nutzen?

Ja, über die ODBC-Datenquelle „EasyMySQL“, sofern sie beim Setup mitinstalliert wurde.

Auf Port 3306 läuft schon ein anderer Datenbankserver.

Dann verwendet EasyMySQL diesen („externer Server“) und startet keinen eigenen. Soll das nicht so sein, das andere Programm (zum Beispiel XAMPP) beenden und EasyMySQL neu starten.

Der Server startet nicht.

Server-Log öffnen und die letzten roten Zeilen lesen, dann Server → Neu starten. Hilft das nicht: Sicherungen & Reparatur → Server retten.

Welche Sprache und welches Design hat das Programm?

Standard sind Englisch und der dunkle Modus. Deutsch und ein helles Design lassen sich in den Einstellungen wählen.

Aktualisiert es sich selbst?

EasyMySQL prüft beim Start und alle sechs Stunden auf neue Versionen. Herunterladen und Installieren startest du selbst.
