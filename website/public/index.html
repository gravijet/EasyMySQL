EasyMySQL

MariaDB-Server und Datenbank-Verwaltung für Windows

EasyMySQL bringt einen MariaDB-Server mit und startet ihn, sobald das Programm läuft. Dazu kommen ein SQL-Editor, Tabellen zum Bearbeiten, ER-Diagramme und automatische Sicherungen.

Für Windows herunterladen

Portable Version und Prüfsummen

Funktionen

  • SQL-Editor

    Beliebig viele Anweisungen pro Datei, jedes Ergebnis in einem eigenen Reiter. Vorschläge beim Tippen, EXPLAIN, ein Formatierer und Export als CSV, JSON, SQL oder Markdown.

  • Tabellen

    Ein Doppelklick öffnet die Daten. Zellen direkt bearbeiten, mit WHERE filtern. Spalten, Indizes und Fremdschlüssel ändern oder eine neue Tabelle im Designer bauen.

  • ER-Diagramm

    Zeichnet die Tabellen und Beziehungen einer Datenbank. Automatisch oder von Hand angeordnet, Export als SVG oder als CREATE-TABLE-Skript.

  • Abfrage-Assistent

    SELECT aus Bausteinen zusammensetzen, vom einfachen FROM bis zu WITH, UNION und Fensterfunktionen. Das erzeugte SQL steht immer daneben.

  • Projekte

    Ein Projekt ist ein Ordner mit SQL-Dateien. Dazu Befehlsliste, Schnellöffnen, Suche in Dateien und ein Verlauf der letzten 3000 Anweisungen.

  • Sicherungen

    Vor DROP, TRUNCATE und DELETE ohne WHERE wird die Datenbank zuerst gesichert. Dazu ein Zeitplan und ein Reparaturwerkzeug, falls nach einem Stromausfall etwas hakt.

Der Server läuft im Infobereich weiter, wenn das Fenster geschlossen wird. Dazu ein ODBC-Treiber für Excel und Access, die Einrichtung von Visual Studio Code in einem Schritt, ein Handbuch auf F1, und die Oberfläche gibt es auf Deutsch und Englisch, dunkel oder hell.

  1. Installieren

    Setup starten. Meldet Windows einen unbekannten Herausgeber, auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“ klicken. Die portable Version wird nur entpackt und ändert PATH nicht.

  2. Starten

    Beim ersten Start richtet EasyMySQL den Datenbankserver automatisch ein.

  3. Verbinden

    Server 127.0.0.1, Port 3306, Benutzer root, kein Passwort. In der Eingabeaufforderung: mysql -u root

Fragen

Muss ich MariaDB extra installieren?

Nein. Setup und portable ZIP enthalten einen vollständigen MariaDB-Server samt Kommandozeilenwerkzeugen wie mysql und mysqldump.

Ist der Server von anderen Rechnern erreichbar?

Nein. Er nimmt standardmäßig nur Verbindungen vom eigenen PC an.

Was passiert, wenn ich das Fenster schließe?

Das Fenster verschwindet, der Server läuft weiter und das Symbol bleibt im Infobereich neben der Uhr. Richtig beenden über Datei → Beenden oder das Menü des Symbols. Mit Windows startet der Server nicht von selbst.

Auf Port 3306 läuft schon ein anderer Datenbankserver.

Dann verwendet EasyMySQL diesen („externer Server“) und startet keinen eigenen. Soll das nicht so sein, das andere Programm (zum Beispiel XAMPP) beenden und EasyMySQL neu starten.

Der Server startet nicht.

Server-Log öffnen und die letzten roten Zeilen lesen, dann Server → Neu starten. Hilft das nicht: Sicherungen & Reparatur → Server retten. Der alte Datenordner bleibt dabei unverändert liegen.

Aktualisiert es sich selbst?

EasyMySQL sucht beim Start und alle sechs Stunden nach neuen Versionen. Herunterladen und Installieren startest du selbst.
