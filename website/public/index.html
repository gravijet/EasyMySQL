EasyMySQL

Datenbank, SQL und Java in einer App.

Windows Portable macOS Linux

Alles für Datenbanken in einem Programm.

EasyMySQL ist Datenbankserver, SQL-Editor und Entwicklungsumgebung zugleich. Du installierst ein Programm, öffnest es und kannst sofort arbeiten: Der Server wird mit eingerichtet und startet von selbst.

Läuft auf
Windows, macOS und Linux
Datenbank
MariaDB, passt zu MySQL
Sprachen
Deutsch und Englisch
Aussehen
Hell oder dunkel

SQL-Editor

Vorschläge passend zu deinen Tabellen. Fehler werden erklärt und mit einem Klick behoben.

  • Strg + . behebt Tippfehler und falsche Namen
  • Abfragen formatieren und den Ausführungsplan ansehen
  • Ergebnisse als CSV, JSON oder SQL speichern

Tabellen

Werte ändern wie in einer Tabellenkalkulation. Strg + Z macht es rückgängig.

  • Spalten umbenennen, verschieben und löschen
  • Neue Zeile mit einem Klick
  • Tabellen kopieren und zusammenführen

ER-Diagramme

Deine Datenbank als Bild, automatisch gezeichnet.

  • Linien zeigen, welche Tabellen zusammengehören
  • Auch große Datenbanken bleiben lesbar
  • Als SVG oder SQL exportieren

Query Builder

Abfragen zusammenklicken und dabei SQL lernen.

  • Für SELECT, INSERT, UPDATE und DELETE
  • Das fertige SQL siehst du live daneben
  • Jeder Schritt lässt sich rückgängig machen

Java

Projekte mit fertiger Datenbankverbindung. Schreiben, starten, debuggen.

  • Neues Projekt mit Klassen für deine Tabellen
  • Java und Treiber lädt EasyMySQL selbst
  • Tests ausführen und mit Haltepunkten debuggen

Git

Änderungen sichern und vergleichen.

  • Änderungen Zeile für Zeile ansehen
  • Zweige anlegen, wechseln und zusammenführen
  • Der Verlauf zeigt, was wann geändert wurde

In drei Schritten startklar

  1. Befehl kopieren

    Füge ihn in PowerShell (Windows) oder ins Terminal (macOS, Linux) ein.

  2. EasyMySQL öffnen

    Der Datenbankserver startet von selbst mit.

  3. Loslegen

    Datenbank anlegen, Tabelle erstellen, erste Abfrage schreiben.

Gut zu wissen

Brauche ich noch XAMPP?
Nein. Der Datenbankserver ist dabei und startet mit EasyMySQL. Nur für Webseiten mit PHP brauchst du weiterhin einen Webserver.
Wie verbinde ich mich aus anderen Programmen?
Wie gewohnt: localhost, Port 3306, Benutzer root, kein Passwort. Das lässt sich in den Einstellungen ändern.
Kann ich meine alten Datenbanken mitnehmen?
Ja. EasyMySQL importiert SQL-Dateien, CSV, SQLite und ganze Datenbanken von einem anderen MySQL- oder MariaDB-Server.
Geht es auch ohne Installation?
Unter Windows ja: Die portable Version entpackst du und startest sie direkt.
Was passiert beim Schließen?
Der Server wird sauber beendet. Wenn du möchtest, läuft er im Hintergrund weiter.
Auf welchen Systemen läuft es?
Windows 10 und 11, macOS ab Version 11 und Linux mit 64 Bit.
