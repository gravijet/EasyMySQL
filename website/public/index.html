Was ist EasyMySQL?

EasyMySQL ist ein Programm für die Arbeit mit Datenbanken. Der Datenbankserver wird bei der Installation mit eingerichtet und läuft, sobald du EasyMySQL öffnest. XAMPP und phpMyAdmin brauchst du für Datenbanken deshalb nicht mehr. Du schreibst SQL, bearbeitest Tabellen und siehst dir die Datenbank als ER-Diagramm an. Wer mit Java auf die Datenbank zugreift, kann das im selben Fenster tun.

SQL-Editor

Beim Tippen schlägt der Editor Tabellen und Spalten aus deiner Datenbank vor. Wenn eine Abfrage nicht funktioniert, markiert er die Stelle und sagt dir, was falsch ist. Vieles kann er auch selbst korrigieren.

Tabellen

Werte änderst du direkt in der Tabelle, so wie in Excel. Auch Spalten kannst du dort umbenennen, verschieben oder löschen, ohne dafür SQL zu schreiben.

ER-Diagramme

EasyMySQL zeichnet aus deiner Datenbank ein ER-Diagramm. Du siehst alle Tabellen und wie sie über Fremdschlüssel zusammenhängen. Das Diagramm lässt sich als Bild speichern.

Query Builder

Hier klickst du Tabellen, Spalten und Bedingungen zusammen und siehst daneben, welches SQL daraus entsteht. Das hilft vor allem, wenn du SQL gerade erst lernst.

Java

Für Java legt EasyMySQL ein Projekt an, in dem die Verbindung zur Datenbank schon funktioniert. Du schreibst den Code, startest ihn und suchst Fehler mit dem Debugger. Java selbst musst du nicht extra installieren.

Git

Mit Git hältst du fest, was du geändert hast, und kannst jeden früheren Stand wieder ansehen. EasyMySQL zeigt dir die geänderten Zeilen, bevor du sie als Commit speicherst.

Warum zu EasyMySQL wechseln?

  • Deine Datenbank geht nicht einfach kaputt. EasyMySQL fährt den Server sauber herunter, wenn du das Fenster schließt oder Windows ausschaltest. Nach einem Absturz oder Stromausfall prüft es beim nächsten Start alle Tabellen.
  • Backups laufen von selbst. Beim Start, danach alle zwei Stunden und vor jedem Löschen legt EasyMySQL eine Sicherung an. Eine gelöschte Tabelle holst du damit wieder zurück.
  • Startet der Server nicht mehr, gibt es eine Rettung. EasyMySQL legt den alten Datenordner beiseite, rettet daraus, was sich retten lässt, und holt den Rest aus der letzten Sicherung.
  • Kein Terminal mehr. Bei XAMPP startest du den Server im Control Panel und tippst SQL ins Terminal. Hier startet der Server von selbst, und Tabellen und Ergebnisse siehst du in einem Fenster.
  • Es hält sich selbst aktuell. Updates lädt und installiert EasyMySQL im Hintergrund, während du weiterarbeitest. Auch MariaDB bringt es auf die neueste Version und sichert vorher alle Datenbanken.
  • Es sieht aus wie ein Programm von heute. Aufgeräumt, dunkel oder hell, mit Tabs wie in einer Entwicklungsumgebung. Jeden Befehl findest du über eine Suche, in der ein paar Buchstaben genügen.
  • Es hilft dir bei Fehlern. EasyMySQL erklärt Fehlermeldungen und bietet gleich einen Knopf zum Beheben an. Fehlt zum Beispiel eine Datenbank oder Tabelle, legt es sie mit einem Klick an.
  • Deine Arbeit geht nicht verloren. Abfragen werden beim Tippen gespeichert und sind nach einem Neustart wieder da. Zu jeder Datei gibt es frühere Fassungen, und der Verlauf merkt sich die letzten 3000 Anweisungen.
  • Java und Git sind schon dabei. Für ein Java-Programm zu deiner Datenbank brauchst du keine zweite Entwicklungsumgebung. Java lädt EasyMySQL selbst herunter.
  • Von außen kommt niemand an deine Daten. Der Server nimmt nur Verbindungen von deinem eigenen PC an, solange du es nicht anders einstellst.
  • Du kannst XAMPP erst einmal behalten. EasyMySQL bringt seinen eigenen Datenbankserver mit. Läuft beim Start schon ein anderer, etwa der von XAMPP, verwendet es stattdessen diesen.
  • Die KI kennt deine Tabellen. Im eingebauten Chat beschreibst du, was du brauchst, und bekommst eine Abfrage, die zu deiner Datenbank passt.
