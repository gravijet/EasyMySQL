EasyMySQL

Deine eigene Datenbank, schnell eingerichtet

EasyMySQL bringt einen MariaDB-Server mit und lässt dich in einem Fenster mit deinen Daten arbeiten: Abfragen schreiben, Tabellen bearbeiten, Diagramme zeichnen, Sicherungen aufbewahren.

Für Windows herunterladen

Was es kann

  • Server inklusive

    MariaDB gehört zum Programm und startet mit ihm. Du musst nichts weiter installieren.

  • Abfragen schreiben

    Ein Editor mit Vorschlägen beim Tippen und übersichtlichen Ergebnissen. Exportieren geht als CSV, JSON oder Markdown.

  • Tabellen bearbeiten

    Daten ansehen, filtern und direkt in der Tabelle ändern. Neue Tabellen legst du an, ohne SQL zu schreiben.

  • Zusammenhänge sehen

    Das Diagramm zeigt, wie die Tabellen einer Datenbank zusammenhängen. Du kannst es umordnen und als Bild exportieren.

  • Abfragen zusammenklicken

    Aus Bausteinen eine Abfrage zusammensetzen. Das fertige SQL steht gleich daneben.

  • Sicherungen

    Vor riskanten Befehlen wird automatisch gesichert, außerdem nach einem Zeitplan.

Herunterladen

Für Windows, 64-bit. Kostenlos und quelloffen.

Installer Portable (ZIP)

Zeigt Windows eine Warnung vor einem unbekannten Herausgeber, auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“ klicken.

Fragen

Muss ich MariaDB extra installieren?

Nein, es ist dabei.

Was passiert, wenn ich das Fenster schließe?

Der Server läuft im Hintergrund weiter und das Symbol bleibt neben der Uhr. Beenden geht über Datei → Beenden. Mit Windows startet er nicht von selbst.

Kommen andere Rechner an meine Daten?

Nein. Der Server nimmt standardmäßig nur Verbindungen vom eigenen PC an.

Aktualisiert es sich selbst?

EasyMySQL sucht regelmäßig nach neuen Versionen und sagt dir Bescheid. Wann du installierst, entscheidest du.
